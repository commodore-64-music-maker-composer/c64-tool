# Final Fantasy IX Cheat Engine table

This folder contains the Cheat Engine table supplied for Final Fantasy IX.

- File: `Final Fantasy IX.ct`
- Original table label: `Final Fantasy IX | 2020-08-06`
- Original author attribution in the table: mul0 (mul0.com)
- Included entries: battle flags (Godmode, infinite MP, full trance, full ATB), minimum 50 items, and a small set of character XP/stat entries.
- The supplied table has 23 entries total. It is a starting/reference table, not a complete trainer.
- It has not been verified against the supplied `FF9.exe` or a live Steam game process.

Open the game, then open the CT file in Cheat Engine and attach to `FF9.exe`. Save before experimenting with memory edits.
